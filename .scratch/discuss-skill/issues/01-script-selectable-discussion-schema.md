# 01 — Script selects the discussion reply schema; stub answers per round

**What to build:** a consultation request can ask for the discussion reply schema, and such a run goes all the way through prepare → run → wait → collect: Codex gets the discussion schema, the reply is classified against it, and the run is cleaned up — while every existing `ask` and `review` consultation behaves exactly as before. The test stub can give a different reply on each call and records each call's prompt and command line at a fixed, numbered location, so later tickets can grade round by round. Prefactor for the `discuss` skill (Plan slice S1; spec: "Discussion reply schema", "Testing Decisions — Seam 1").
